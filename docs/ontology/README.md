# Effect ontology

One file per `CardEffect` member, in declaration order: every boundary of the tag, when it was
decided, the cards that settled it and how many reviewed cards it moved. These files are the
canonical record of the rulings. Rulings that cut across every tag (a card earns a tag only for what
it does on its own; the effects deliberately absent) are in the `<summary>` of
[`CardEffect.cs`](../../ScatoloneDownloader/Mtg/CardEffect.cs). The one-line tooltips are in
[`EffectGlossary.cs`](../../ScatoloneDownloader/Mtg/EffectGlossary.cs).
